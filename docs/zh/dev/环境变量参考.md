# MinerU 主干环境变量参考

> **用途**: 记录 MinerU 主干代码（非 `custom/`）中所有 `MINERU_*` 及其他配置型环境变量的名称、默认值、作用、使用方式和代码位置。
> **最后更新**: 2026-09-20
> **适用版本**: MinerU 3.4.4

---

## 说明

- **设置方式**: 所有参数通过**环境变量**设置，运行时生效，无需修改代码。
- **优先级**: 环境变量 > 代码默认值（不存在 JSON 配置文件回退机制——这一点与 `custom/` 目录不同）。
- **使用示例**:
  ```bash
  # export 方式（影响后续所有命令）
  export MINERU_DEVICE_MODE=cuda
  mineru -p doc.pdf -o output/

  # 内联方式（仅本次有效）
  MINERU_PDF_RENDER_DPI=300 mineru -p doc.pdf -o output/

  # Docker Compose
  services:
    mineru-api:
      environment:
        - MINERU_DEVICE_MODE=cuda
  ```

## 一、核心引擎参数

影响后端选择、模型加载和设备分配的基础参数。

| 环境变量 | 类型 | 默认值 | 作用 | 定义位置 |
|---------|------|--------|------|---------|
| `MINERU_DEVICE_MODE` | str | 自动检测 | 强制指定计算设备：`cpu` / `cuda` / `npu` / `mps`。不设时按 cuda→mps→npu→gcu→musa→mlu→sdaa→cpu 自动检测。 | `config_reader.py:76` |
| `MINERU_FORMULA_ENABLE` | bool | 跟随调用方 | 强制开关公式识别。不设时由 CLI 参数 `-f` 控制。设为 `true`/`false` 可覆盖。 | `config_reader.py:111` |
| `MINERU_TABLE_ENABLE` | bool | 跟随调用方 | 强制开关表格识别。不设时由 CLI 参数 `-t` 控制。 | `config_reader.py:117` |
| `MINERU_OCR_DET_MASK_INLINE_FORMULA_ENABLE` | bool | 跟随调用方 | 启用行内公式 OCR 检测掩码。设为 `true` 时 OCR 检测阶段自动屏蔽行内公式区域，减少文字框误检。 | `config_reader.py:123` |
| `MINERU_MODEL_SOURCE` | str | `huggingface` | 模型权重下载源：`huggingface` / `modelscope` / `local`。首次初始化时自动下载模型。 | `models_download_utils.py:18` |
| `MINERU_TOOLS_CONFIG_JSON` | str | `mineru.json` | JSON 配置文件的路径。支持绝对路径；相对路径时搜索 `~/<文件名>`。用于配置 S3 存储、LaTeX 分隔符、LLM 辅助和模型目录。 | `config_reader.py:14` |

**使用示例：**
```bash
# 强制 CPU 推理（即使有 GPU）
MINERU_DEVICE_MODE=cpu mineru -p doc.pdf -o out/

# 使用魔搭下载模型（国内加速）
MINERU_MODEL_SOURCE=modelscope mineru -p doc.pdf -o out/

# 指定配置文件位置
MINERU_TOOLS_CONFIG_JSON=/etc/mineru/prod.json mineru -p doc.pdf -o out/
```

## 二、Pipeline 参数

控制本地 Pipeline 后端（`pipeline` backend）的推理行为。

| 环境变量 | 类型 | 默认值 | 作用 | 定义位置 |
|---------|------|--------|------|---------|
| `MINERU_LMDEPLOY_DEVICE` | str | `""` | PipeLine 中 OCR 检测的 batching 设置。值为 `corex` 时禁用 det batch。 | `pipeline_analyze.py:334`, `model_init.py:297` |
| `MINERU_FORMULA_CH_SUPPORT` | bool | `False` | 中文公式模型切换。`true` 时使用 `pp_formulanet_plus_m`（中文友好）；`false` 时使用 `unimernet_small`（通用）。 | `model_init.py:23` |
| `MINERU_DONOT_CLEAN_MEM` | - | 未设置 | 存在即生效。处理 ≥10 页 PDF 后跳过内存清理，用于排查内存相关问题。 | `model_json_to_middle_json.py:281` |
| `MINERU_PROCESSING_WINDOW_SIZE` | int | `64` | 滑窗处理窗口大小，每次处理 N 页后释放缓存。影响内存占用和批处理效率。最小值 1。 | `config_reader.py:129` |

**使用示例：**

| `MINERU_LMDEPLOY_BACKEND` | str | `""` | lmdeploy 后端模式：`pytorch` / `turbomind`。 | `vlm_analyze.py:192`, `lmdeploy_server.py:62` |

```bash

# 昇腾设备适配
MINERU_LMDEPLOY_DEVICE=ascend mineru -p doc.pdf -o out/ -b vlm-auto-engine
```

## 四、Hybrid 参数

控制 Hybrid 后端（默认，`hybrid-auto-engine`）的行为——VLM 提供布局 + pipeline 做精炼。

| 环境变量 | 类型 | 默认值 | 作用 | 定义位置 |
|---------|------|--------|------|---------|
| `MINERU_HYBRID_BATCH_RATIO` | float | 自动（基于显存） | 固定混合推理的 batch 比例。默认根据可用 VRAM 自动推断。 | `hybrid_analyze.py:658` |

| `MINERU_VIRTUAL_VRAM_SIZE` | int | 自动检测 | 覆盖显卡报告显存大小（单位 GB）。用于模拟低显存环境或强制调整 batch 分配。 | `model_utils.py:218` |

**使用示例：**
