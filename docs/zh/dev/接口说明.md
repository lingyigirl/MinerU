## 一、HTTP REST API

### 1.1 mineru-api (FastAPI 服务)

**启动命令**: `mineru-api --host 0.0.0.0 --port 8000`

#### `GET /health`

健康检查。

**响应** (200):
```json
{
  "status": "ok",
  "version": "3.2.0",
  "api_protocol_version": 1,
  "max_concurrent_requests": 3,
  "processing_window_size": 64
}
```

#### `POST /file_parse`

同步解析文档，等待结果后返回。

**Content-Type**: `multipart/form-data`

**表单参数**:

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `files` | File (可多个) | 必填 | 待解析文件 |
| `backend` | str | `hybrid-auto-engine` | 解析后端 |
| `parse_method` | str | `auto` | 解析方式: auto / txt / ocr |
| `lang_list` | str (JSON数组) | `[]` | 语种列表 |
| `formula_enable` | bool | true | 公式识别 |
| `table_enable` | bool | true | 表格识别 |
| `image_analysis` | bool | true | 图片/图表分析 |
| `server_url` | str | 空 | VLM/HTTP 客户端服务地址 |
| `start_page_id` | int | 0 | 起始页 |
| `end_page_id` | int | 99999 | 结束页 |
| `return_md` | bool | true | 返回 Markdown |
| `return_content_list` | bool | false | 返回 content_list JSON |
| `return_middle_json` | bool | false | 返回中间 JSON |
| `return_model_output` | bool | false | 返回模型原始输出 |
| `draw_span_bbox` | bool | false | 绘制 span bbox |
| `response_format_zip` | bool | false | ZIP 格式响应 |

**响应**: 
- 默认: JSON (含 markdown / content_list 等字段)
- `response_format_zip=true`: ZIP 文件下载

#### `POST /tasks`

提交异步解析任务。

**请求体**: 与 `POST /file_parse` 相同。

**响应** (201):
```json
{
  "task_id": "uuid-string",
  "status": "pending",
  "status_url": "/tasks/{task_id}",
  "result_url": "/tasks/{task_id}/result",
  "created_at": "2026-06-30T10:00:00+00:00"
}
```

#### `GET /tasks/{task_id}`

查询异步任务状态。

**响应** (200):
```json
{
  "task_id": "uuid-string",
  "status": "pending" | "processing" | "completed" | "failed",
  "queued_ahead": 0,
  "created_at": "...",
  "updated_at": "...",
  "error": null
}
```

#### `GET /tasks/{task_id}/result`

获取异步任务结果。

**响应**: 
- 任务完成: 与 `POST /file_parse` 相同格式的结果
- 任务未完成: 302 重定向到 `/tasks/{task_id}`
- 任务失败: 400 附错误信息

### 1.2 mineru-router (负载均衡网关)

**启动命令**: `mineru-router --host 0.0.0.0 --port 8002`

接口完全兼容 `mineru-api`，额外支持：

#### `GET /health`
返回路由器自身健康状态及所有 upstream worker 的状态。

**响应** (200):
```json
{
  "status": "ok",
  "workers": [
    {
      "server_id": "local-gpu0",
      "base_url": "http://127.0.0.1:8001",
      "healthy": true,
      "queue_depth": 2,
      "active_tasks": 1
    }
  ]
}
```

**关键 CLI 参数**:

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--upstream-url` | (可重复) | 远程上游 mineru-api 地址 |
| `--local-gpus` | `auto` | 本地 GPU: auto / none / 0,1 |
| `--worker-host` | `127.0.0.1` | 本地 worker 绑定地址 |

## 二、Python 内部接口

## 三、关键枚举

### BlockType (`mineru/utils/enum_class.py`)

主要文档元素类型：
```
IMAGE, TABLE, CHART, CODE, TEXT, TITLE,
INTERLINE_EQUATION, INLINE_EQUATION,
IMAGE_BODY, IMAGE_CAPTION, IMAGE_FOOTNOTE,
TABLE_BODY, TABLE_CAPTION, TABLE_FOOTNOTE,
HEADER, FOOTER, PAGE_NUMBER, FOOTNOTE,
ABSTRACT, DOC_TITLE, PARAGRAPH_TITLE,
VERTICAL_TEXT, LIST, INDEX, REF_TEXT, DISCARDED
```

### MakeMode

```python
MakeMode.MM_MD           # 多模态 Markdown
MakeMode.NLP_MD          # NLP Markdown
MakeMode.CONTENT_LIST    # 结构化 JSON v1
MakeMode.CONTENT_LIST_V2 # 结构化 JSON v2
```

### 后端名称字符串

```
pipeline              ← 纯小模型（支持 CPU）
vlm-auto-engine       ← VLM 自动选择推理引擎
vlm-vllm-engine       ← VLM + vLLM
vlm-lmdeploy-engine   ← VLM + LMDeploy
vlm-http-client       ← VLM 远程客户端
hybrid-auto-engine    ← Hybrid 自动选择引擎
hybrid-vllm-engine    ← Hybrid + vLLM
hybrid-http-client    ← Hybrid 远程客户端
```
