# 修复计划：电子回单 KVP 提取结果变差

## 上下文

银行电子回单（含有 `rowspan`/`colspan` 的复杂 HTML 表格）被 S1 分类器误判为 `FORM_KVP`，路由到本地 OCR + 空间规则配对的 KVP 管线，导致只提取到 3 个字段（原 Hybrid 管线可提取完整表格，20+ 字段）。

**根本原因**：[doc_classifier.py](mineru/utils/custom/doc_classifier.py) 的分类逻辑中，`FORM_KVP` 优先级高于 `STRUCTURED_TABLE`，且 `STRUCTURED_TABLE` 要求 `kvp_count < 3`。电子回单同时包含大量 KVP 关键词（户名、账号、开户行…）和银行印章，满足 `kvp_count >= 3 and has_stamp` 条件，被直接判为 KVP 类型，**但这类文档实际上是表格布局**，更适合 Hybrid（VLM 表格提取 + OCR 精炼）。

**期望结果**：电子回单路由到 `DOCUMENT_PARSE` → `hybrid-auto-engine`，由 Hybrid 管线生成结构化 HTML 表格。

---

## 方案：分类逻辑修正 + 可选 KVP 增强（两阶段）

### Phase 1（立即）：修正文档分类，避免表格型文档误入 KVP

**核心思路**：在 `classify_document()` 中增加一个轻量级的表格结构检测。当文档**同时**具有高密度 KVP 关键词和表格特征时，优先路由到 `DOCUMENT_PARSE`（Hybrid 后端）。

#### 修改文件

**1. [doc_classifier.py](mineru/utils/custom/doc_classifier.py)**

**1a. 新增 `_has_repeating_labels()` 辅助函数**（~25 行）

在 `_count_table_keywords()` 之后插入：

```python
def _has_repeating_labels(text: str) -> bool:
    """检测 OCR 文本中是否存在重复的标签模式（表格结构特征）。

    表格型文档（如银行回单）的 OCR 输出中，同一行会出现多个相同标签
    （如 "户名...账号...户名...账号"），这是表格网格布局的标志。
    简单 KVP 表单中每个标签通常只出现一次。

    Returns:
        True 如果检测到重复标签模式。
    """
    if not text:
        return False
    # 在同一行中检测重复的关键标签
    repeating_patterns = [
        r"户名.*户名",      # 两列表格：付款人户名 + 收款人户名
        r"账号.*账号",      # 两列表格：付款人账号 + 收款人账号
        r"开户行.*开户行",  # 两列表格：付款人开户行 + 收款人开户行
        r"金额.*金额",      # 多金额字段
    ]
    for p in repeating_patterns:
        if re.search(p, text):
            return True
    return False
```

**1d. 修改分类逻辑**（[doc_classifier.py:362-371](mineru/utils/custom/doc_classifier.py#L362-L371)）

将 OCR 可用时的分类规则修改为：

```python
# OCR 可用时的标准分类规则
# 先检测表格结构：有重复标签模式 = 表格型文档，Hybrid 处理
has_repeating = _has_repeating_labels(text_sample)
if has_repeating and kvp_count >= 3 and table_kw_count >= 3:
    # 表格型 KVP 文档（如银行回单、对账单）→ Hybrid 处理表格
    logger.info(
        "检测到表格+KVP混合结构（重复标签模式），路由到通用解析"
    )
    doc_type = DocType.DOCUMENT_PARSE
elif kvp_count >= 3 and (has_stamp or ocr_difficulty in ("medium", "high")):
    doc_type = DocType.FORM_KVP
elif kvp_count >= 5 and not has_stamp:
    doc_type = DocType.FORM_KVP
elif table_kw_count >= 5 and kvp_count < 3:
    doc_type = DocType.STRUCTURED_TABLE
else:
    doc_type = DocType.DOCUMENT_PARSE
```
