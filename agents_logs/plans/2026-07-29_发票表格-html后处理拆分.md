# 方案 1：发票表格 HTML 后处理拆分

## Context

### 问题
MinerU VLM 模型在解析扫描版增值税发票 PDF 时，表格数据行的 HTML 输出为单列合并单元格：
```html
<td colspan="8">项目名称 规格型号 单位 数量 单价 金额 税率/征收率 税额
*供电*电费 千瓦时 403480 0.7164205165064 289061.35 13% 37577.97(度)</td>
```
导致 "数量↔403480"、"单价↔0.7164205165064" 等键值无法对应。

### 根因
VLM 模型对扫描件表格的列分割线识别不精确，输出了 `colspan` 过大的合并单元格。这是模型层面的限制，在通用表格识别和特定发票格式之间产生了差距。

### 目标
在不修改 VLM 模型的前提下，通过后处理将合并单元格拆分为独立列，使数值与表头正确对齐。

---

## 实现方案

### 1. 新增自定义模块：`mineru/utils/custom/table_utils.py`

#### 核心函数

```python
def split_merged_table_cells(html: str) -> str:
    """对 VLM 输出的表格 HTML 做后处理拆分合并单元格。

    当检测到某个 <td> 的 colspan 覆盖整行（>= 总列数的一半），
    且单元格文本内容同时包含表头关键词和多个数据值时，
    尝试基于表头列定义将其拆分为独立的 <td> 元素。

    Args:
        html: VLM 模型输出的原始表格 HTML 字符串。

    Returns:
        拆分后的 HTML 字符串；如果拆分失败则原样返回。
    """
```

#### 算法逻辑

1. **解析 HTML**：用 BeautifulSoup 解析输入 HTML
2. **提取列定义**：遍历所有 `<tr>`，找到包含 `colspan="N"` 且 N >= 4 的行作为候选数据行
3. **识别数据行**：检查候选行的单元格文本是否同时包含——
   - 表头关键词（如 "项目名称"、"数量"、"单价"、"金额"、"税率"、"税额"）
   - 数值数据（如 "403480"、"0.71..."、"289061.35"、"13%"）
4. **解析表头结构**：从该单元格文本中提取表头关键词序列，确定列数 N 和各列的预期关键词
5. **分割数据值**：基于位置特征（关键词之间、数值之间、空格分隔）将文本切分为 N 个片段
6. **重建 HTML**：将拆分后的片段各自包装为 `<td>` 标签，替换原 `<td colspan="N">`

#### 安全保护

- 任何步骤失败 → 返回原始 HTML
- `BeautifulSoup` 解析失败 → 返回原始 HTML
- 拆分后的列数不等于 colspan 值 → 返回原始 HTML
- 通过 `logger.warning()` 记录拆分失败原因

### 2. Hook 点：`mineru/backend/vlm/vlm_middle_json_mkcontent.py`

在 `_format_embedded_html()` 函数中插入 `[自定义]` hook，覆盖所有输出路径（markdown、content_list、content_list_v2）。

修改位置：`_format_embedded_html()` 函数（第 59-61 行），在 `_replace_eq_tags_in_table_html()` 和 `_prefix_table_img_src()` 之后增加一个处理步骤。

```python
def _format_embedded_html(html, img_buket_path):
    """格式化嵌入式表格 HTML。"""
    formatted = _replace_eq_tags_in_table_html(_prefix_table_img_src(html, img_buket_path))
    
    # [自定义] 对 VLM 表格做后处理，拆分过度合并的单元格
    # 合并上游时注意：此 hook 只依赖 mineru/utils/custom/ 下的自定义模块
    try:
        from mineru.utils.custom.table_utils import split_merged_table_cells
        formatted = split_merged_table_cells(formatted)
    except Exception as exc:
        logger.warning(
            f"表格合并单元格拆分失败，将使用原始表格输出: {exc}"
        )
    
    return formatted
```
